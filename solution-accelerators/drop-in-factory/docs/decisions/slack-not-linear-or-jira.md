# Slack, not Linear or Jira

Slack is status, chat, intake and steering. A top-level mention in the factory channel opens a GitHub issue; Foreman's status message for the run starts the status thread, where every follow-up goes. A mention inside either thread is chat with that run, or a command (approve, changes, abandon) checked in code, and never opens another issue. See [Slack approvals, checked in code](slack-approvals-checked-in-code.md).

Linear and Jira are not trackers and not discussion channels. The GitHub issue is the tracker.
