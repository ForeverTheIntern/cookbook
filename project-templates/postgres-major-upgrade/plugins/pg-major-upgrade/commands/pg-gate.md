description: Check whether a gate or block can close, using the gate review skill. Pass a gate ID (G0.2) or a block (0-3); with no argument, reviews the current block.

Use the `pg-upgrade-gate-review` skill on the gate or block I name. If I don't name one, review the current block.

Report each gate as `pass`, `fail` or `needs decision`, with what's missing. Don't set any gate to `Done`.
