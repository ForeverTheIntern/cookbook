# Raw reviewer output

These files are the reviewers' JSON output, unedited, kept so anyone can check the round records against what each reviewer actually said.

They are not vetted. Some findings were wrong and were rejected, and others describe problems that were fixed later. The round records one level up are authoritative: each finding there is marked fixed, rejected (with the reason) or open.

- Don't cite a finding from these files as fact about Postgres or a provider. Check the round record, then the SOP and its `[S-nn]` sources.
- Don't edit them. A correction belongs in the round record.
- Each folder is one round and one target (`round-2-sop`, `round-2-skills`, and so on), with one file per reviewer.
