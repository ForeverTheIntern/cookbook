# Solution Accelerators

A solution accelerator is a complete, working starting point for a common way of using Cursor in your organization. Each one is a self-contained folder with its own docs, setup checks, tests and example CI, so you can copy it into your own repository, configure it, and run it.

| Accelerator | What it does |
| --- | --- |
| [Drop-in Software Factory](drop-in-factory) | Label a GitHub issue, or ask in Slack, and a pipeline of Cursor cloud agents (triage, spec, plan, implement, review, verify) takes it to a pull request ready to merge, with approval gates on GitHub or in Slack. |
